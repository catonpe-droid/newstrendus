GTA 6 PS5 Firmware Update: Why Version 14.23.00 Matters

PS5 owners are being told to install system software 14.23.00 ahead of GTA 6. How to check your console and game update before launch.

NewsTrendus Editorial Desk · November 18, 2026

At a glance: PS5 owners are being told to install system software 14.23.00 ahead of GTA 6. How to check your console and game update before launch.

PS5 players face a new requirement before GTA 6

A PlayStation Support US notice published November 18 advises owners to install a PS5 system software update before playing Grand Theft Auto VI. Reporting from Push Square on November 18 identifies the required version as 14.23.00. Rockstar's own game website still lists the main launch for Thursday, November 19 on PlayStation 5 and Xbox Series X|S.

This update is to the console operating system. It should not be confused with a downloadable GTA VI patch, and it is not an announcement of new missions, graphics modes or other game features.

How to check your PS5 system software

Open Settings → System → System Software → System Software Update and Settings. If your console offers an official update, follow its instructions and allow the installation and restart to finish. A stable internet connection and sufficient free storage can help avoid interruptions. For the official process, see Sony's PS5 system-software support page.

Install software through Sony's supported menu rather than a link circulated on social media. If the PS5 says it is current but the game still is not accessible, inspect the official storefront's unlock status and check PlayStation Support before trying unofficial fixes.

What is different about GTA 6 update 01.002.001?

In addition to the PS5 firmware requirement, Forbes reported on November 17 that GTA VI game update 01.002.001 had rolled out to preloaders. Version 01.002.001 identifies a game patch; version 14.23.00 identifies PS5 system software. Those different numbers refer to separate downloads.

To look for the game patch on PS5, highlight GTA VI from the home screen, press Options and choose Check for Update. If the game is installed but remains locked, a pending release-time entitlement may still be the reason. That does not by itself prove the firmware installation failed.

What should you do today to avoid launch-day problems?

Confirm that the correct GTA VI edition is in your game library, finish any official pre-load, install available console and game updates and leave sufficient free storage. Avoid a full reinstall unless an official troubleshooting instruction calls for it. Check your account's regional store for the release unlock.
